Audit Automation Portfolio (Python | RPA)

👤 Overview

This repository showcases automation tools built to streamline audit and accounting processes using Python. The focus is on reducing manual effort, improving accuracy, and enabling faster financial analysis.

---

🔧 Projects Included

🔹 Duplicate Invoice Detection Tool

Automates the identification of duplicate invoices to prevent overpayments and strengthen financial controls.

Key Features:

- Detects duplicates using invoice number, date, and amount
- Handles large datasets efficiently
- Reduces risk of duplicate payments

Tech Stack: Python (Pandas), Excel

---

🔹 Bank Reconciliation Automation Tool

Automates reconciliation of bank statements with ledger data to identify mismatches and discrepancies.

Key Features:

- Matches transactions using amount and reference logic
- Highlights unmatched entries
- Generates structured outputs for audit review

Tech Stack: Python (Pandas), Excel

---

📊 Impact

- Reduced manual audit effort
- Improved accuracy in financial checks
- Faster reconciliation process
