Audit Automation Portfolio (Python | RPA)

👤 Overview

This repository showcases Python-based automation tools designed to improve efficiency in audit and accounting processes.

---

🔧 Projects Included

🔹 Duplicate Invoice Detection Tool

Identifies duplicate invoices using key parameters to prevent overpayments.

Features:

- Detects duplicates using Invoice Number, Date, Amount
- Handles large datasets
- Improves audit accuracy

---

🔹 Bank Reconciliation Tool

Automates matching of bank statements with ledger records.

Features:

- Matches transactions based on amount
- Identifies unmatched entries
- Generates reconciliation outputs

---

🧠 Skills Demonstrated

- Python (Pandas)
- Financial Analysis
- Audit Automation

---

🚀 How to Run

pip install -r requirements.txt
python duplicate-invoice-detection/main.py
python bank-reconciliation/main.py

---

📌 Use Case

Designed for auditors and finance professionals to automate repetitive financial checks.
